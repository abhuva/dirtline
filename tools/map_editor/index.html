FIELD NOTES

A recipe, not a painted map.

Add operations from the left. Drag between an output dot and an input dot in either direction to connect them. Dropping onto an occupied input replaces its connection; outputs can feed multiple inputs. A wire follows your pointer and matching targets light up. Click × beside a connected input to disconnect it. Escape or dropping on empty space cancels the drag. You can also click an output dot, then any matching input dot, or choose and clear connections in Node Settings. Undo/redo includes connection changes. Drag a node header to move the node. Select a node to inspect its intermediate result. Click Pin settings to keep its controls open, then select a downstream node to watch its preview while tweaking the pinned node. Unpin settings makes the controls follow selection again. Duplicate and Delete act on the node named in Node Settings. The temporary iteration slider also previews the pinned node's effect downstream.

Sand is floor; dark green is wall. Masks use 1 for wall/selected and 0 for floor/unselected. Fields range from 0 to 255; Threshold turns a field into a mask. Combine performs union, intersection, subtraction or XOR on the wall masks.

Cellular rules list neighbour counts that create or retain a wall, excluding the center. Birth 5–8 / survival 4–8 reproduces the original rule. Every iteration reads the previous grid. Outside the grid is solid; the border setting forces edge cells to remain walls. An optional mask limits changes to selected cells, except the forced border.

Playable world enforces a two-cell border, keeps the largest four-connected floor area, creates a fallback clearing if needed, and places the spawn and six outposts. Inspect its input to see what finalization changed. The refined collision view uses the same C++ corner rounding and town footprints as the ROM.

Preview any stage, compare its input/output, or inspect nine consecutive seeds. The inspector's iteration preview does not change the saved recipe. Ctrl+Z / Ctrl+Shift+Z undo and redo edits. Changes are kept in this browser; export JSON to keep a portable copy.

To use a recipe in the game, export a valid Playable world output, save it as maps/wasteland.json, then run ./build.ps1 and ./test.ps1. The game generates it at runtime; export does not bake the map. Fixed mode uses the exported seed; Random mode supplies a fresh seed.

Limits: 32 nodes, six live 4 KiB buffers, 64 × 64 cells. Reordering nodes on the canvas does not affect randomness. Changing the Random stream changes only that generator. Version 2 recipes have separate wall/floor and Ground materials outputs. Ground IDs are bytes (0-255): 0 sand, 1 gravel, 2 hardpan, 3 asphalt. IDs without artwork are preserved and render as sand. Use Fill material for a base, Field to materials to turn noise into areas, and Paint material to replace IDs under a mask. Set a Ground materials node as the ground output. Each ID covers one 128-pixel cell; material edges are not blended. Original recipes retain their original ground rules until a ground output is assigned. The Natural ground preset demonstrates both outputs. Game textures shows the shared in-game tile rules; Full map render opens an 8192-square map with zoom and PNG export. The render includes terrain and settlement graphics, without cars or HUD.

Version 3 adds Enemy spawns and Decoration outputs, applied to the final world. Connect a 0-255 field to input A, or leave it empty for uniform placement. Enemy spawns sets a target count, minimum spacing, and optional starter encounters. Zero weights forbid spawns; higher values bias selection among reachable sector anchors. The preview reports the achieved count. Decoration uses density and four relative type weights on a finer 32px placement grid. Zero density or all-zero type weights disables it. Keep roads clear excludes road patches. Constant field and Mask to field provide simple density controls. The Populated wasteland preset demonstrates these branches. Spawns toggles location markers in both previews and full PNG exports; decoration is visible in Game textures. Cosmetics do not change collision or driving grip.
